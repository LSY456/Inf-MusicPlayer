
项目简介

支持本地与网络流媒体文件的流畅播放，涵盖常见音视频格式解码、音量调节、倍速播放及音画同步，提供带实时预览的进度条精准控制和多种播放模式（顺序、随机、单曲循环）；内置智能播放列表管理系统，支持拖拽文件添加、历史记录追溯及快捷键自定义操作，同时具备截图捕获、全屏切换、界面主题个性化定制等辅助功能，结合网络流媒体加载、错误自动恢复机制及配置云端同步能力，确保用户在多场景下获得高效稳定的使用体验





# U-Inf Player
本项目基于Qt 6.5.3开发框架构建，需搭配MinGW 11.2 64位编译工具和CMake 3.24以上版本进行开发。
使用FFmpeg 5.1.3用于支持MP3、MP4等常见格式的解码；TagLib 1.13.1用于读取歌曲信息；OpenCV 4.7.0用于智能歌词匹配等进阶功能。开发调试建议使用 CLion或Qt Creator最新版本，若遇到界面显示异常，可通过临时关闭"硬件加速渲染"功能排查问题。
安装完成后，需在终端输入qmake --version确认开发工具版本为6.5.3，运行ffmpeg -decoders检查是否支持H.265等主流视频格式。首次启动时建议播放软件自带的测试文件，若出现无法播放的情况，请检查是否遗漏了对应的解码器插件。在部分特殊硬件设备上，可能需要重新配置Qt多媒体模块的底层驱动适配层。
